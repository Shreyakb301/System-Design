# Visual Concepts: System Design & Data Structures

An interactive learning platform designed for engineers who learn by seeing. This project transforms complex system architecture and data structure concepts into engaging, gamified simulations.

## 🚀 Features

### 🎮 Gamified Challenges
*   **System Architect Challenge**: Step into the role of a lead engineer. Design complex systems, manage budget, and scale infrastructure to meet real-time performance goals.
*   **Algorithm Arena**: Master memory management and pointer logic through interactive puzzles. Fix broken linked lists and optimize array layouts.

### 📊 Interactive Visualizations
*   **Concept Demonstrations**: Topic pages (Load Balancing, Caching, Arrays, etc.) feature live, interactive simulations using our custom-built rendering engines.
*   **Real-time Metrics**: systems simulate latency, reliability, and cost based on your architectural decisions.

### 🧩 Core Topics
*   **System Design**: Load Balancing, Caching, CDNs, Microservices, Scalability, and more.
*   **Data Structures**: Arrays, Strings, Linked Lists, Trees, Graphs, and Complexity Analysis.

## 🛠 Tech Stack

*   **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Components**: [shadcn/ui](https://ui.shadcn.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Feedback**: [canvas-confetti](https://github.com/catdad/canvas-confetti)

## 🏁 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to begin your architect training.
